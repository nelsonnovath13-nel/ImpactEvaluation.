# Academic Study Portal

A single static website containing multiple course handbooks under one Vercel deployment.

## Courses
1. Consultancy Skills
2. Impact Evaluation (L1, L2 and L3)
3. Project Financing, Budget & Procurement
4. Principles of Monitoring & Evaluation

## Deployment
Upload this folder to the GitHub repository and connect that repository to Vercel. Vercel uses `index.html` as the portal entry point, so one deployment produces one main link.

The Impact Evaluation course files are preserved in `impact-evaluation/` to retain its existing lecture structure.

## Final Source Audit
Open `audit-final.html` for the final source inventory, corrections, duplicate-file handling, and completeness checks performed before deployment.
